# python-daily 🐍

Daily Python learning log. One commit per day minimum.

## Structure
```
week-XX/
  day-XX-topic.py    # practice scripts
  notes.md           # optional: key concepts from that day
```

## Progress Tracker
| Week | Days Committed | Topics Covered |
|------|---------------|----------------|
| 01   | 0/7           | -              |

## Rules
- Every practice script gets committed. No "it's too small" excuses.
- Commit message format: `add: <topic> - <one line description>`
- Example: `add: loops - fizzbuzz and list iteration practice`
